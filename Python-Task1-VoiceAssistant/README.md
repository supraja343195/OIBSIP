# Python Voice Assistant

## Project Overview

This project is a beginner-level Python Voice Assistant that listens to voice commands and performs useful actions.

The assistant can:
- Listen to voice input through a microphone
- Respond to greetings
- Tell the current time
- Tell the current date
- Search the web for a requested topic
- Provide spoken responses using text-to-speech
- Handle unclear or unrecognized speech gracefully

## Technologies Used

- Python 3.12
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser
