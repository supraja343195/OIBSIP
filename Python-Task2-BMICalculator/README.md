# BMI Calculator

## Project Overview

A beginner-level Python program that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features

- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI
- Classifies BMI into health categories
- Displays BMI rounded to 2 decimal places
- Validates invalid and negative inputs

## BMI Categories

- Underweight: BMI < 18.5
- Normal: BMI 18.5–24.9
- Overweight: BMI 25–29.9
- Obese: BMI >= 30
